# Mukhlisin Niamillah · Personal Portfolio

Website portofolio pribadi milik **Mukhlisin Niamillah** (dikenal juga sebagai *Niam Munehisa*). Seorang Trader, Investor, dan Stockmarket Analyst yang memiliki ketertarikan mendalam pada psikologi, teknologi, dan pasar finansial. 

Website ini dibangun menggunakan HTML, CSS, dan Vanilla JavaScript murni tanpa framework, dengan fokus pada interaksi UI yang halus dan modern.

## Fitur Utama

- **Interactive 3D Flip Card**: Kartu profil pada bagian Hero yang dapat dibalik (klik atau drag) dengan efek 3D, *spring physics*, *tilt on hover*, dan efek *glare*.
- **Dynamic Shape Grid Background**: Latar belakang animasi berbasis Canvas yang interaktif, merespons pergerakan kursor, dan memiliki efek *cascade* saat diklik.
- **Responsive Design**: Tata letak yang menyesuaikan dengan baik di perangkat desktop maupun mobile.
- **Desain Minimalis & Elegan**: Menggunakan kombinasi font *Playfair Display* dan *Inter* dengan palet warna bumi (*earth tones*) yang memberikan kesan profesional dan tenang.
- **Aksesibilitas**: Dilengkapi dengan atribut ARIA, dukungan navigasi keyboard, dan penghormatan terhadap *prefers-reduced-motion*.

## Teknologi yang Digunakan

- **HTML5**: Struktur semantik.
- **CSS3**: Styling kustom, CSS Variables, Flexbox, Grid, dan animasi 3D (Transform, Perspective).
- **Vanilla JavaScript**: Logika interaksi, animasi *spring physics*, dan manipulasi Canvas API.
- **Canvas API**: Untuk merender latar belakang *Shape Grid*.
- **Google Fonts**: Inter & Playfair Display.
- **Font Awesome**: Ikon-ikon UI.

## Struktur File

- `index.html`: File utama yang berisi struktur HTML, styling CSS, dan inisialisasi script.
- `flip-card.js`: Modul JavaScript untuk membuat komponen kartu 3D interaktif (FlipCard).
- `shape-grid.js`: Modul JavaScript untuk membuat latar belakang animasi grid interaktif berbasis Canvas (ShapeGrid).

## Cara Menjalankan

Karena ini adalah proyek statis murni, Anda tidak memerlukan *build tools* atau server backend yang rumit.

1. Clone repositori ini atau unduh semua file.
2. Pastikan file `index.html`, `flip-card.js`, dan `shape-grid.js` berada dalam satu direktori.
3. Buka file `index.html` langsung di browser (Google Chrome, Firefox, Safari, dll).
4. *Atau*, untuk pengalaman terbaik, gunakan ekstensi **Live Server** di VS Code.
